# Menu de Restaurante 🍽️
Este projeto apresenta um menu de restaurante interativo, desenvolvido com HTML, CSS e JavaScript. Ele exibe os itens do menu em diferentes categorias e permite que o usuário filtre os itens por categoria. 


# 🚀 Funcionalidades
* Exibição de Itens do Menu: o menu é carregado com uma lista de pratos, incluindo título, preço, descrição e imagem. 
* Filtragem de Itens: o usuário pode filtrar os itens do menu por categoria, como Café da Manhã, Almoço, Milkshakes e Jantar.
  

# 🖥️ Como Usar
1. Clone o repositório:

```bash
git clone https://github.com/analuisaabarbosa/menu-restaurante.git
```
2. Abra o arquivo index.html no navegador ou Live Server para usar.

# Estrutura do Menu 🍲
O menu é composto por um conjunto de objetos, cada um representando um item de comida, com as seguintes propriedades:
* id: Identificador único do item.
* title: Título do item.
* category: Categoria do item (Café da Manhã, Almoço, etc.).
* price: Preço do item.
* img: Caminho para a imagem do item.
* desc: Descrição do item.

# Personalização ⚙️
Você pode facilmente adicionar ou remover itens do menu, alterando a lista no arquivo app.js. 

Para adicionar uma nova categoria, basta modificar a lista de categorias no JavaScript e ajustar a estrutura HTML conforme necessário.
